# Modul 5 - Database Toko

1. Nyalakan MySQL di XAMPP.
2. Impor `toko.sql` lewat phpMyAdmin. File ini membuat tabel dan 10 data contoh per tabel.
3. Jalankan aplikasi melalui `http://localhost/Modul-5/`.

Kolom dan pilihan form di `index.php` mengikuti tabel dalam `toko.sql`. Jika tabel lama sudah ada, cadangkan dahulu, hapus tabel lama, lalu impor ulang agar strukturnya sesuai.
